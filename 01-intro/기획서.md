# 기획서: 자기소개 웹페이지

## 누가 쓰나

수업에서 처음 만난 친구들

## 만들 것

가상의 인물을 소개하는 한 페이지짜리 웹페이지

## 디자인

- 사용 권한이 있는 몬치치 이미지를 배경이 투명한 형태로 사용한다.
- `images/monchhichi.png`를 크기와 방향을 다르게 하여 배경 12곳에 풍성하게 배치한다.
- 소개 글을 쉽게 읽을 수 있도록 글 영역에는 밝은색 반투명 상자를 사용한다.
- 배경색 변경 버튼을 눌러도 캐릭터 무늬와 글이 잘 보이게 한다.
- 전체 글씨는 참고 이미지처럼 붓글씨 느낌이 나는 명조체로 표현한다.
- "안녕, 나는 구름이야!" 제목의 양옆에 몬치치 이미지를 한 쌍씩 배치한다.

## 가상 인물 설정

- 20대 여성 대학생
- 별명: `[요청할 때 정하기]`
- 한 줄 소개: `[별명과 함께 요청할 때 정하기]`
- 실제 인물이 아닌, 누가 보아도 가상인 정보만 사용

## 기능

1. 별명과 한 줄 소개를 보여 준다.
2. 좋아하는 것 3가지를 보여 준다.
3. 버튼을 누르면 배경색이 바뀐다.

## 조건

- HTML, CSS, JavaScript는 `index.html` 파일 하나에 모두 작성한다.
- 배경 장식용으로 `images/monchhichi.png` 이미지 파일 하나를 사용한다.
- 외부 라이브러리, 서버, 데이터베이스는 사용하지 않는다.
- 실명과 연락처는 넣지 않는다.
- 사용 권한이 확인된 이미지만 사용하고 인터넷 이미지 주소는 직접 연결하지 않는다.
- 화면 문구와 코드 주석은 한국어로 작성한다.

## 완료 기준

- [ ] `01-intro/index.html`을 더블클릭하면 브라우저에서 바로 열린다.
- [ ] 별명과 한 줄 소개가 화면에 보인다.
- [ ] 좋아하는 것 3가지가 화면에 보인다.
- [ ] 배경이 투명한 몬치치 이미지가 여러 곳에 보인다.
- [ ] 몬치치 이미지 12개가 빈 공간을 자연스럽게 채운다.
- [ ] 배경의 캐릭터 무늬 때문에 소개 글이 가려지지 않는다.
- [ ] 제목 양옆의 몬치치가 카드 안쪽 빈 공간을 자연스럽게 채운다.
- [ ] 글씨가 붓글씨 느낌의 명조체로 보이면서도 읽기 쉽다.
- [ ] 버튼을 누르면 배경색이 바뀐다.
- [ ] 실명과 연락처가 들어 있지 않다.
